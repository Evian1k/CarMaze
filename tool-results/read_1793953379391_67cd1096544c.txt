     1→// CARMAZE — Automotive ecosystem schema (SQLite / Prisma)
     2→// Money is stored as integer minor units (cents) with explicit currency (default KES).
     3→// SQLite has no enums/arrays/JSON: use String fields (JSON stored as strings).
     4→
     5→generator client {
     6→  provider = "prisma-client-js"
     7→}
     8→
     9→datasource db {
    10→  provider = "sqlite"
    11→  url      = env("DATABASE_URL")
